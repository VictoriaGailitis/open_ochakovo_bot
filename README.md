# Очаково: изнутри — открываем вкус к делу

Карьерный VK Mini App для знакомства студентов и выпускников с людьми, профессиями и возможностями «Очаково».

**«Открываем вкус к делу»** — концепция HR-кампании. **«Очаково: изнутри»** — её цифровой инструмент. **«У каждого вкуса есть команда»** — история о людях, благодаря которым появляется знакомый продукт.

Статус: демонстрационный прототип, разработка и интеграция продолжаются. Содержание и границы проекта основаны на рабочей концепции команды от 24 октября 2026 года. Прототип не является официальным сервисом найма компании.

## Идея и задача

За знакомыми напитками стоят мастерство, знания и ответственность команды. Приложение помогает заглянуть внутрь профессии: попробовать учебную задачу, понять содержание работы, посмотреть карьерные предложения и сделать следующий шаг.

Предлагаемое сообщение кампании: «Здесь твои знания становятся настоящим продуктом. Открой профессию, освой дело и увидь свой вклад в результат команды».

Главное целевое действие — **отправленный отклик на подходящую практику или вакансию**. Заполненный профиль, баллы и прохождение игр учитываются отдельно. Рост найма и конверсии — гипотезы для будущего пилота, а не доказанные результаты прототипа.

## Для кого

Основная аудитория — студенты и выпускники 18–26 лет, прежде всего старшие курсы профильных направлений:

- пищевые технологии и биотехнологии;
- химия, анализ и лабораторный контроль;
- оборудование, механика, мехатроника и автоматизация;
- производственные и складские направления СПО.

Дополнительный сценарий — сезонная работа с возможностью совмещения с учёбой. Пользователь может выбрать «Пока не определился», поменять интерес и посмотреть все предложения.

## Путь пользователя

1. Узнать о приложении по рекламе или QR и увидеть короткое объяснение.
2. Заполнить профиль: ФИО, контакт, дату рождения, интересующее направление, готовность выйти и вуз/колледж. График и согласие на будущие предложения указываются отдельно.
3. Перейти сразу к практике/вакансиям либо познакомиться с профессиями через задания и исторический тест.
4. Посмотреть задачи и условия, проверить сохранённые данные и отдельно подтвердить отклик.
5. Следить за статусом заявки, записаться на встречу и вернуться к новым уровням и своему прогрессу.

Игры и баллы не ограничивают право откликнуться и не определяют приоритет найма. Игровые ситуации служат знакомству с принципами работы и не оценивают профессиональную квалификацию.

## Разделы приложения

| Задания | Самостоятельные игры, исторический тест, уровни и прогресс |

## Игры и обучение

| Игра | Основное действие | Статус прототипа |
| --- | --- | --- |
| Сигнал → действие | Собрать правила из условий и действий, запустить поток и проверить алгоритм | 3 уровня |
| Передай движение | Собрать передачу из шестерён и открытых ремней, проверить направление вращения | 3 уровня |
| Лабораторный детектив | Выбрать исследования, исключить несовместимые образцы и приложить доказательства | 3 уровня |
| Собери и доставь | Выбрать доступные партии, разместить заказ и построить маршрут сбора | 3 уровня |
| Открываем историю | Ответить на вопросы об истории и брендах, прочитать объяснения и источники | Законченный тест |
| Разберись в смене | Исследовать 12 показателей, схему, журнал и проверки; собирать наблюдения и обоснованный вывод | 2 причинно разных раунда |

За новый завершённый уровень начисляются баллы. Повторное прохождение не приносит бесконечных призовых баллов, подсказки доступны без штрафа. Пропуск дня не сжигает прогресс. За сохранение профиля, отклик и запись на событие призовые баллы не начисляются.

## Технологии

React + TypeScript + Vite, VK Bridge, Python HTTP API и SQLite. Веб-интерфейс запускается на платформе VK Mini Apps; сервер отвечает за идентификацию, сохранение данных, проверку игровых решений и транзакции.

## Запуск

Нужны Node.js 20.19+ или 22+, npm и Python 3.11+.

```sh
npm ci
npm run dev
```

Открыть http://127.0.0.1:5188. Эта команда запускает фронтенд и API на 3001, включает **только локальный** демонстрационный вход. Профиль и результаты сохраняются в `.data/ochakovo.sqlite3`; личность демопользователя — в localStorage браузера. Используйте вымышленные данные.

```sh
npm run build
npm test
```

После сборки `npm start` раздаёт приложение и API с http://127.0.0.1:3001. При таком запуске демонстрационный вход отключён. Для локальной проверки собранной версии: `DEV_AUTH=1 npm start`.

## Что реализовано

### Практика и наставники

Добавлен раздел `/#/practice` и отдельный кабинет наставника `/#/mentor`: даты и план первых дней, цели с проверкой результата, личный календарь, встречи, добровольные опросы, обращения, отзывы, результаты и интерес к продолжению работы. Данные сохраняются в SQLite. Новая админка не входит в модуль; назначения и административные операции подключаются отдельно. [Авторизация, создание аккаунтов и контракт интеграции](docs/practice.md). Сущности, права и задачи будущей админки включены в [общий план](docs/admin-entities.md#12-внутренний-раздел-практикант-и-наставник--implemented).


- Первый вход и обязательный профиль в два шага; изменение данных и отдельное необязательное согласие на будущий контакт. Регистрация доступна с 18 лет: клиент показывает отдельный экран с открывашкой, сервер отклоняет профиль несовершеннолетнего.
- Вкладки «Для тебя», «Задания», «Карьера», «События»; профиль через аватар, баланс через верхнюю панель, URL и кнопка назад браузера.
- «Разберись в смене»: 12 показателей с графиками, схема потока, журнал и проверки, собственные наблюдения с заметками, конструктор вывода и серверная проверка доказательств. Два раунда с разными причинами; до 30 баллов за каждый.
- Ещё четыре самостоятельные игры по три уровня: визуальные правила «Сигнал → действие», передача вращения «Передай движение», исследования «Лабораторный детектив», размещение заказа и маршрут «Собери и доставь».
- Игровая зона и рабочие сцены v5 используют библиотеку из 16 самостоятельных модулей. Оформление, условия уровней и серверные правила разделены для будущего редактора уровней.
- Законченный исторический тест с источниками. Черновики и результаты сохраняются на сервере; решение проверяется сервером; один уровень приносит баллы только один раз.
- Практика/вакансии, фильтры, подтверждение отклика с копией профиля, история и статусы заявок. Игровой прогресс не ограничивает доступ к отклику.
- Календарь, карточки событий, запись, отмена, учёт свободных мест и список своих записей. Внутри мероприятий — активности с названием, описанием, баллами и статусом выполнения.
- Сканер QR-кодов в «Событиях» и карточках мероприятий: сканер VK, камера браузера, распознавание изображения и ручной ввод. Сервер отмечает выполнение и начисляет баллы за активность один раз. Управление активностями организаторов запланировано в отдельной админке.
- Баланс и журнал операций, каталог наград, цель, транзакционный обмен с учётом остатков.
- Приглашение к экскурсиям после основного маршрута; уведомления VK только по запросу пользователя.
- Защищённый кабинет HR `/#/admin`, просмотр принятых заявок и изменение статусов. Ключ берётся из `.data/admin-token` или `ADMIN_TOKEN`, в клиент не включается.

В «Разберись в смене» игрок самостоятельно выбирает материалы, закрепляет и редактирует наблюдения, строит гипотезу и обосновывает следующий шаг. Принимаются разные достаточные наборы доказательств; свободные заметки не оцениваются автоматически. Повторный раунд меняет причину одинакового симптома, поэтому механика не сводится к запоминанию ответа. Прямое вмешательство в оборудование не является действием игрока.

Вакансии, оплаты, события и награды демонстрационные. Отклики действительно сохраняются в API и видны HR, но не отправляются во внешнюю кадровую систему; реальные сообщения от компании не имитируются.

## Подключение VK

Для созданного приложения **54850900** подготовлен запуск через Docker Compose с HTTPS и постоянной базой. Пошаговые команды и необходимые данные владельца — в [инструкции размещения](docs/vk-deployment.md).

Платформа VK Mini Apps запускает веб-приложение внутри VK; собственный сервер нужен для проверки подписи, данных, заявок и баллов.

1. Создать приложение VK Mini Apps и получить его ID и защищённый ключ.
2. Разместить сборку и API на одном HTTPS-домене. Можно использовать Dockerfile; каталог `.data` подключить как постоянный volume.
3. Передать серверу `VK_APP_ID`, `VK_APP_SECRET`, `ADMIN_TOKEN`; при отдельном домене фронтенда указать `ALLOWED_ORIGINS`. Пример — `.env.example`.
4. Указать HTTPS URL в настройках платформы. `DEV_AUTH` в развёрнутом приложении оставлять выключенным.
5. Открыть приложение из VK и проверить init, подпись запуска и восстановление профиля. Секретный ключ никогда не передаётся в Vite/client env.

Сборка включает `VKWebAppInit`, получение имени и разрешение уведомлений. Сервер проверяет HMAC подписи, ID приложения, время запуска и идентификатор пользователя. Фактическая проверка внутри VK требует ID/секрета приложения и настроенного HTTPS URL; локальная демонстрация её не заменяет. Основа интеграции — [официальный VK Bridge](https://github.com/VKCOM/vk-bridge) и [параметры запуска VK](https://github.com/VKCOM/vk-apps-launch-params).

## Структура

- `src/App.tsx` — навигация, профиль, карьера, события, баллы, HR.
- `src/games/` — игровые редакторы, механики и тесты.
- `src/styles.css`, `src/components/Art.tsx`, `public/assets/` — дизайн и локальные ассеты Figma.
- `server/catalog.json` — единый каталог, уровни и демонстрационное содержание.

- [Модульные уровни](docs/game-levels.md) — текущий контракт оформления и условий игры.
- [Сущности будущей админки](docs/admin-entities.md) — поля, связи, ограничения и отличие реализованных сущностей от будущих возможностей; [JSON-схема](docs/admin-entities.json).
- `server/app.py`, `server/solutions.py`, `server/tests/` — API, проверка решений, база и тесты.
- Приватные выгрузки дизайна, настройки и локальная база исключены из Git.
- `docs/backend.md`, `docs/games.md`, `docs/design.md` — контракты и технические подробности.

Перед реальным пилотом нужны утверждённые предложения/события/награды, политика обработки персональных данных, процедуры отзыва/удаления и подтверждённое профессиональное содержание.
