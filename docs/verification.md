# Проверка прототипа

Дата: 24 октября 2026 года. Проверка выполнена на локальной сборке; публичный сервис найма не запускался.

## Автоматические проверки

- `npm run build`: TypeScript и production-сборка Vite проходят.
- `npm test`: 17 серверных и 5 тестов игровых механик проходят.
- Dockerfile подготовлен; локальная попытка сборки остановилась при загрузке базового образа из Docker Hub из-за TLS handshake timeout. Сборка контейнера не подтверждена.
- Все 13 уровней имеют проверенные решения. Неправильные решения не начисляют баллы.
- Проверены HMAC запуска VK, идентификатор приложения, срок действия и подмена параметров.
- Проверены разграничение пользователей, восстановление черновиков, миграция существующей базы и защита от запоздавших записей по монотонной версии.
- Проверены однократное начисление при параллельных запросах, обмен при ограниченном балансе/остатке, вместимость события, отмена и повторная запись.
- Подтверждены отдельный отклик с копией профиля, повторная отправка без дублирования, защищённый просмотр и смена статуса HR.
- Проверена раздача собранного приложения и недоступность базы, ключа администратора, исходников сервера и обхода каталога через URL.

## Проверка интерфейса

Через браузер и настоящий локальный API пройдены:

1. Первый вход, оба шага профиля и восстановление после перезагрузки.
2. Предложение по выбранному интересу, подтверждение отклика и отображение принятой заявки. Заявка дополнительно найдена через защищённый API HR.
3. Карточка события, подтверждение записи, отображение своей записи и отмена. Свободные места меняются с 20 до 19 и обратно до 20.
4. Все три уровня каждой из четырёх игр и исторический тест — всего 13 завершений отдельным тестовым пользователем, итог 630 баллов.
5. Трасса правил, размещение шестерён, исследования и доказательства, резерв партии, поворот упаковки и маршрут склада.
6. Сохранение выбора при немедленной перезагрузке до debounce; повтор теста без нового начисления; управление Enter.
7. В составе приложения — завершение уровня, изменение баланса с 0 до 50, демонстрационный обмен, списание до 0 и уменьшение остатка награды на один.
8. Основная навигация, доступ к профилю и баллам, локальные ассеты и мобильная компоновка шириной 390 px. Дополнительно проверены главная, игровая иллюстрация и интерактивная сетка на ширине 320 px: горизонтального переполнения нет.

Тестовые анкеты и операции хранятся только в локальной базе, исключённой из репозитория. Временный игровой стенд удалён.

## Что требует внешней настройки

- Запуск внутри реального VK-клиента: нужны ID приложения, защищённый ключ и настроенный HTTPS URL. Проверка криптографии автоматическими тестами не заменяет проверку VK Bridge на устройстве.
- Реальные вакансии, события, награды, условия участия и выдачи должны быть подтверждены компанией.
- Перед обработкой реальных данных необходимы утверждённая политика и процедуры отзыва согласия/удаления.
- Профессиональное содержание учебных моделей требует проверки экспертами. Игры не определяют пригодность кандидата.
- «Разберись в смене» намеренно не реализована; её карточка имеет состояние «Скоро».

Работа с дизайном и состояние подключения Figwright описаны в `docs/design.md`. Приватные адреса и исходные выгрузки дизайна не публикуются.
